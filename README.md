# Bizarre Gems (в русском каталоге — «Алмазная братва»)

Головоломка на время для Яндекс Игр. Godot 4.7, рендер Compatibility, веб-экспорт без потоков.

Нажми на пустую клетку: игра берёт первый камень в каждом из четырёх направлений, и все камни,
которые встретились хотя бы дважды, выбиваются. 2 камня дают +2 очка, 3 камня +4 и +1 с,
4 камня +6 и +2 с, промах −1 с. На старте 120 секунд. Поле 23×15 (на вертикальном экране 15×23),
270 камней: 10 видов по 27.

## Структура

```
project.godot           настройки (окно 720×720, stretch canvas_items/expand → любой экран)
export_presets.cfg      пресет «Yandex Web»; в html/head_include живёт JS-мост window.YG к SDK
scenes/main.tscn        корневая сцена (UI собирается в scripts/main.gd)
scripts/
  board_logic.gd        правила, без графики (class_name BoardLogic)
  board_view.gd         отрисовка поля, эффекты, ввод мышью/тачем/клавиатурой
  main.gd               состояния игры, интерфейс, реклама, лидерборд
  yandex.gd   (autoload Yandex)  обёртка SDK; вне браузера всё работает как заглушки
  save.gd     (autoload Save)    рекорд и настройки звука: user:// + облако Яндекса
  sfx.gd      (autoload Sfx)     звуки и музыка, глушится на время рекламы
  i18n.gd     (autoload L)       тексты ru / en / tr
assets/                 всё сгенерировано tools/gen_assets.py, шрифты под OFL
tests/test_logic.gd     тесты правил
tools/
  gen_assets.py         пересобирает камни, иконки, текстуры, звуки, иконку и обложку
  serve.py              локальный сервер сборки с имитацией SDK (tools/mock/sdk.js)
store/                  материалы для карточки игры: иконка, обложка, скриншоты, тексты
build.sh                импорт → тесты → экспорт → build/bizarre-gems-yandex.zip
```

## Сборка

```sh
./build.sh                      # нужны godot 4.7 и шаблоны экспорта web_nothreads_*
python3 tools/serve.py          # http://127.0.0.1:8060/  (?lang=en, ?lang=tr)
```

Локально `/sdk.js` подменяется имитацией: реклама показывается заглушкой, в таблице лидеров два
тестовых игрока. В редакторе Godot SDK нет, награда за рекламу выдаётся сразу.

Автоигра для проверки эффектов и скриншотов (только debug-сборка):
`godot --headless --path . --export-debug "Yandex Web" build/webdebug/index.html`, затем
`python3 tools/serve.py 8061 build/webdebug` и открыть `http://127.0.0.1:8061/?autoplay`.

Перегенерировать ассеты: `python3 tools/gen_assets.py` (нужны rsvg-convert, Pillow, numpy).

## Тестовая версия в браузере (GitHub Pages)

Играть: https://electrocrem.github.io/bizarre_gems/  (язык: `?lang=en`, `?lang=tr`; автоигра: `?autoplay`)

```sh
./tools/deploy_pages.sh         # debug-сборка в ветку gh-pages, Pages обновится за 1–2 минуты
```

Здесь нет SDK Яндекса: реклама за награду выдаётся сразу, межстраничной нет, таблица лидеров
работает только в Яндекс Играх. В настройках внизу видна строка с размером экрана и масштабом.

## Тестовая сборка для Android

```sh
./build_android.sh              # build/android/bizarre-gems-debug.apk, ставит на телефон через adb
```

Нужны шаблоны Godot `android_debug.apk`/`android_release.apk`, Android SDK в `~/Android/Sdk`
(build-tools, platform-tools) и JDK, указанный в настройках редактора
(`export/android/java_sdk_path`). APK подписан debug-ключом, это сборка только для проверки.
Пакет `com.electrocrem.bizarregems`, экран поворачивается по датчику, «Назад» ставит паузу и
закрывает окна, из меню выходит из игры. SDK Яндекса на Android нет: реклама за награду
выдаётся сразу, межстраничной нет, таблица лидеров пишет, что работает в Яндекс Играх.

## Загрузка в Яндекс Игры

1. Консоль разработчика: https://games.yandex.ru/console → «Добавить приложение».
2. **Лидерборды**: раздел «Лидерборды» → создать два с техническими названиями `score` («Классика») и `score_bright` («Яркий режим»)
   (по убыванию, тип «число»). Без него таблица будет пустой.
3. Архив: «Черновик» → загрузить `build/bizarre-gems-yandex.zip` (index.html в корне архива).
4. Иконка 512×512: `store/icon_512.png`. Обложки 800×470 для каждого языка: `store/cover_800x470_ru.png`, `_en.png`, `_tr.png`.
   Скриншоты: `store/screenshots/` (1920×1080 и 1079×1918).
5. Тексты и SEO для полей карточки: `store/listing.md` (проверка лимитов: `python3 tools/check_listing.py`).
6. Языки: русский, английский, турецкий. Платформы: десктоп и мобильные, обе ориентации.
7. Реклама: межстраничная перед «Ещё раз» (не чаще раза в 61 с), за вознаграждение:
   +15 секунд после конца времени или перемешивание, когда ходов нет (по разу за партию).

Что уже сделано под требования Яндекса: `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop`
вокруг активной игры, пауза и выключение звука при рекламе, при сворачивании вкладки и по
событиям `game_api_pause/resume`, язык из `ysdk.environment.i18n.lang`, сохранения в облаке
игрока, контекстное меню и выделение текста отключены.
