# Bizarre Gems (в русском каталоге — «Алмазная братва»)

Головоломка на время для Яндекс Игр. Godot 4.7, рендер Compatibility, веб-экспорт без потоков.

Нажми на пустую клетку: игра берёт первый камень в каждом из четырёх направлений, и все камни,
которые встретились хотя бы дважды, выбиваются. 2 камня дают +2 очка, 3 камня +4 и +1 с,
4 камня +6 и +2 с, промах −1 с. На старте 120 секунд. Поле 23×15 (на вертикальном экране 15×23),
270 камней: 10 видов по 27.

## Что есть в игре

- Режимы: «Классика» (оригинальные правила), «Уровни» (главы по 20 уровней со своим фоном,
  боссами с правилом главы и наградами), «Яркий забег», «Шаги», «Головоломка», обучение.
- Особые камни: джокер, ящик, цепь, лёд, бомба с отсчётом, хамелеон.
- Испытание дня (общее поле «Яркого забега», +20 кристаллов в день), задания, достижения, ежедневный подарок, коллекция из 11 паков плиток,
  статистика, «Лучший удар» в итогах.

## Как добавлять фичи

**Как всё связано.** `main.gd` знает правила и состояние партии. Экраны (`scenes/ui/*.tscn`)
только показывают данные и сообщают сигналами, что нажал игрок. Кнопки подключены к методам
скрипта прямо в сцене (вкладка «Узел → Сигналы» в редакторе). Экран открывает другой экран
сигналом `navigate.emit(&"tasks")`, где имя — это имя узла экрана в `main.tscn` в snake_case.
А для действий игры (начать партию, посмотреть рекламу) у экрана есть свои сигналы, их
подключает `main.gd` в `_connect_screens()`.

**Тексты.** Если в поле `text` у Label или Button написан ключ из `i18n/strings.csv` (например,
`play`), Godot сам покажет перевод. Новый текст = новая строка в CSV с колонками ru/en/tr.
В коде: `L.t("key")` или `L.t("key", {"n": 5})`, если в тексте есть `{n}`.

**Внешний вид.** Стиль текста выбирается полем *Theme Type Variation* (Title, Heading, Body,
Muted, Bold, Caption, Number, NumberGold, Crystals), стиль кнопки — PrimaryButton,
IconButton, RoundButton, DailyCard, ChallengeCard. Сами стили правятся в `ui/theme.tres`, и это
меняет все экраны сразу.

**Новый экран**, например «Магазин»:
1. Создайте `scenes/ui/shop.tscn`: корень `PanelContainer` (диалог по центру) или
   `MarginContainer` (на весь экран, тогда в инспекторе включите *Full Screen*), внутри — что нужно.
2. Скрипт `scripts/ui/shop.gd` начинается с `extends Screen`. В `refresh()` заполняете данные,
   кнопку «Закрыть» подключаете к методу, который делает `click()` и `navigate.emit(&"back")`.
3. Перетащите сцену в `main.tscn`: диалог — внутрь узла `Center`, полноэкранный — рядом с `Home`.
   Назовите узел `Shop` и сделайте его невидимым. `main.gd` сам найдёт экран по имени.
4. Откройте её откуда угодно: `navigate.emit(&"shop")`. Если «Назад» на Android должно вести
   не на главный экран, допишите это в `_on_back()`.

**Новое правило игры** — `board_logic.gd` (поле и ходы) и `_on_slot()` в `main.gd` (что
происходит после удара). Логику без графики удобно проверять тестом в `tests/test_logic.gd`.

**Проверка в Windows.** Запускайте `./tools/test_isolated.ps1 -Godot 'путь/к/Godot_console.exe'`
из PowerShell 7. Он проверяет изоляцию сохранений, прогоняет правила и все экраны/режимы
в отдельной копии проекта без Godot AI. Ошибки Godot и `FAIL` завершают проверку с ошибкой.
Команды, ограничения платформ и запуск отдельных наборов: [tests/README.md](tests/README.md).
Прямые запуски тестов и тестовые команды в `build.sh` / `build_android.sh` пока используют
обычный профиль игры; для проверки интеграции используйте изолированный runner.
Все автоматические проверки, включая Windows/OpenGL, запускаются с `--audio-driver Dummy`.
Глобальную громкость и реальные настройки игры для тестов не менять. Проверка с слышимым
звуком требует отдельной согласованной безопасной процедуры; APK автоматически не запускается.

## Сборка

```sh
./build.sh                      # нужны godot 4.7 и шаблоны экспорта web_nothreads_*
python3 tools/serve.py          # http://127.0.0.1:8060/  (?lang=en, ?lang=tr)
```

Локально `/sdk.js` подменяется имитацией: реклама показывается заглушкой, в таблице лидеров два
тестовых игрока. В редакторе Godot SDK нет, награда за рекламу выдаётся сразу.

Автоигра для проверки эффектов и скриншотов (только debug-сборка):
`godot --headless --audio-driver Dummy --path . --export-debug "Yandex Web" build/webdebug/index.html`, затем
`python3 tools/serve.py 8061 build/webdebug` и открыть `http://127.0.0.1:8061/?autoplay`.

Перегенерировать ассеты: `python3 tools/gen_assets.py` (нужны rsvg-convert, Pillow, numpy).

## Тестовая версия в браузере (GitHub Pages)

Играть: https://electrocrem.github.io/bizarre_gems/  (язык: `?lang=en`, `?lang=tr`; автоигра: `?autoplay`)

```sh
./tools/deploy_pages.sh         # debug-сборка в ветку gh-pages, Pages обновится за 1–2 минуты
```

Здесь нет SDK Яндекса: реклама за награду выдаётся сразу, межстраничной нет, таблица лидеров
работает только в Яндекс Играх. В настройках внизу видна строка с размером экрана и масштабом.

## Тестовая сборка для Android

```sh
./build_android.sh              # build/android/bizarre-gems-debug.apk, ставит на телефон через adb
```

Нужны шаблоны Godot `android_debug.apk`/`android_release.apk`, Android SDK в `~/Android/Sdk`
(build-tools, platform-tools) и JDK, указанный в настройках редактора
(`export/android/java_sdk_path`). APK подписан debug-ключом, это сборка только для проверки.
Пакет `com.electrocrem.bizarregems`, экран поворачивается по датчику, «Назад» ставит паузу и
закрывает окна, из меню выходит из игры. SDK Яндекса на Android нет: реклама за награду
выдаётся сразу, межстраничной нет, таблица лидеров пишет, что работает в Яндекс Играх.

## Загрузка в Яндекс Игры

1. Консоль разработчика: https://games.yandex.ru/console → «Добавить приложение».
2. **Лидерборды**: раздел «Лидерборды» → создать четыре с техническими названиями `score` («Классика»),
   `score_bright` («Яркий забег»), `score_zen` («Шаги») и `stars` («Звёзды уровней»)
   (по убыванию, тип «число»). Без них таблицы будут пустыми.
3. Архив: «Черновик» → загрузить `build/bizarre-gems-yandex.zip` (index.html в корне архива).
4. Иконка 512×512: `store/icon_512.png`. Обложки 800×470 для каждого языка: `store/cover_800x470_ru.png`, `_en.png`, `_tr.png`.
   Скриншоты: `store/screenshots/` (1920×1080 и 1079×1918).
5. Тексты и SEO для полей карточки: `store/listing.md` (проверка лимитов: `python3 tools/check_listing.py`).
6. Языки: русский, английский, турецкий. Платформы: десктоп и мобильные, обе ориентации.
7. Реклама: межстраничная перед «Ещё раз» (не чаще раза в 61 с), за вознаграждение:
   +15 секунд после конца времени или перемешивание, когда ходов нет (по разу за партию и уровень),
   ×2 кристаллы в итогах партии или уровня, подсказка после бесплатной.

Что уже сделано под требования Яндекса: `LoadingAPI.ready()` после загрузки, `GameplayAPI.start/stop`
вокруг активной игры, пауза и выключение звука при рекламе, при сворачивании вкладки и по
событиям `game_api_pause/resume`, язык из `ysdk.environment.i18n.lang`, сохранения в облаке
игрока, контекстное меню и выделение текста отключены.
